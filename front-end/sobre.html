Sobre o projeto

Uma porta de entrada para IA astronomica

O AstroClassifier foi reformulado como uma experiencia didatica para mostrar como modelos de inteligencia artificial podem aprender padroes do universo a partir de tabelas de observacao.

O que ele faz

Recebe medidas fotometricas de um objeto astronomico e estima se ele se parece mais com uma estrela, uma galaxia ou um quasar.

O que ele nao faz ainda

Nesta versao, o projeto nao recebe upload de imagens do ceu. O modelo atual trabalha com dados numericos de brilho, nao com pixels de fotografias.

Como pensar nos dados

Cada filtro funciona como uma janela de cor. Ao comparar o brilho em varias janelas, o modelo encontra pistas sobre temperatura, distancia e tipo de fonte luminosa.
